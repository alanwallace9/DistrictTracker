# Backlog Item: Multiple Guardian Contacts

**Type:** Feature Request / Improvement
**Priority:** Medium
**Date Added:** 2025-11-30
**Source:** Course correction session (Story 2-8b planning)

---

## Description

Currently, guardian contact information (phone, email) can only store one value per field. When a parent requests additional contacts be notified (e.g., "Can you email their dad too?"), the current contact must be overwritten.

## User Need

DAEP administrators need to store multiple contact methods for guardians:
- Primary guardian phone + email
- Secondary guardian phone + email
- Additional emergency contacts

## Proposed Solution (TBD)

Options to explore:
1. **Multiple guardian records** - Link multiple guardian entries to a student
2. **Array fields** - Store multiple phones/emails in arrays
3. **Contact list UI** - Add/remove contacts dynamically

UI design to be determined in future UX session.

## Acceptance Criteria (Draft)

- [ ] Can add additional phone numbers without overwriting existing
- [ ] Can add additional email addresses without overwriting existing
- [ ] Can designate primary vs secondary contacts
- [ ] Can remove additional contacts
- [ ] All contacts visible on student profile

## Related

- Story 2-8b (Inline Student & Placement Editing) - current scope limited to single contact edit
- Epic 2 (Placement Management) or future Epic
